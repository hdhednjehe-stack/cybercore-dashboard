Einrichtung für echten Login
Die Seite wurde als Datei geöffnet. Discord akzeptiert dafür keine Redirect-URL. Öffne einen Terminal im Ordner mit der index.html, starte python -m http.server 3000 (oder npx serve -l 3000) und rufe dann http://localhost:3000/ im Browser auf.

Trage die Client-ID deiner Discord-App ein. Unter OAuth2 → Redirects muss diese Adresse stehen:

Discord fragt das Passwort selbst ab, in seinem eigenen Fenster. Dieses Dashboard sieht es nie. Der Login funktioniert nur über http(s), zum Beispiel http://localhost:3000, nicht über file://.
